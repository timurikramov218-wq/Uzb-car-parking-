# UZB Car Parking

3D-игра про парковку и езду по открытому городу в браузере. Только узбекские машины: Matiz, Damas, Spark, Nexia, Cobalt, Gentra, Tracker, Malibu.

## Что есть
- **Открытый мир**: город с дорогами и перекрёстками, медресе с голубыми куполами, площадь, базар (Bozor), заправка Metan/Benzin, махалля, парки, парковки, горы на горизонте.
- **10 уровней парковки** на автодроме: передом, задом, параллельная, змейка, ёлочка, узкий проезд, гараж и финальный лабиринт. Звёзды и награда в сумах.
- **Гараж**: покупка машин и покраска (11 цветов). Номера в узбекском формате.
- **Онлайн**: создай комнату, отправь друзьям 4-значный код и катайтесь вместе в одном городе. Есть чат (T). Работает через WebRTC (PeerJS), отдельный сервер не нужен.
- Управление с клавиатуры и сенсорное (для телефонов), 4 камеры, мини-карта, звук мотора и сигнал.

## Управление
| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз и задний ход |
| A / D | руль |
| Пробел | ручник |
| C | сменить камеру |
| H | сигнал |
| R | сброс машины |
| T | чат (онлайн) |
| Esc | меню |

## Запуск
Нужен любой статический сервер (из-за ES-модулей файл нельзя открыть двойным кликом):
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
Все библиотеки лежат в `vendor/`, интернет нужен только для онлайн-режима.

## Структура
- `js/cars.js`: машины, их характеристики и 3D-модели
- `js/world.js`: генерация города
- `js/physics.js`: физика машины и столкновения
- `js/levels.js`: уровни парковки
- `js/net.js`: онлайн
- `js/main.js`: игровой цикл, камера, интерфейс, звук
