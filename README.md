# UZB Car Parking

3D-игра про парковку и езду по открытому Ташкенту в браузере. Машины — настоящие 3D-модели Matiz, Damas, Nexia и Malibu, с завода белые.

## Что есть
- **Ташкент**: сквер Амира Темура с кольцом и конной статуей, отель «Узбекистан», музей Темуридов, куранты, Дворец форумов, канал Анхор, арка Эзгулик, площадь Мустакиллик, Tashkent City, мечеть Минор, телебашня, базар Чорсу, Кукельдаш, Хаст-Имам, стадион «Миллий», махалли старого города, панельки Чиланзара и Юнусабада, проспекты с разделителем и чинарами, горы Чимгана на северо-востоке.
- **10 уровней парковки** на автодроме: передом, задом, параллельная, змейка, ёлочка, узкий проезд, гараж и финальный лабиринт. Звёзды и награда в сумах.
- **Гараж**: покупка и покраска. Все машины изначально белые.
- **Светофоры** на всех перекрёстках: фазы север–юг / восток–запад, табло обратного отсчёта, стоп-линии, подсказка в углу экрана и штраф за проезд на красный.
- **Физика**: модель с шинами — плавный руль, на скорости машина недоповорачивает, на ручнике уходит в занос, крен и клевок кузова, визг шин, упругие столкновения.
- Управление с клавиатуры и сенсорное (для телефонов), 4 камеры, мини-карта, звук мотора и сигнал.

## Управление
| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз и задний ход |
| A / D | руль |
| Пробел | ручник |
| C | сменить камеру |
| H | сигнал |
| R | сброс машины |
| Esc | меню |

## Запуск
Нужен любой статический сервер (из-за ES-модулей файл нельзя открыть двойным кликом):
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
Все библиотеки лежат в `vendor/`.

## Структура
- `js/cars.js`: машины, их характеристики и 3D-модели
- `js/world.js`: генерация города
- `js/physics.js`: физика машины и столкновения
- `js/levels.js`: уровни парковки
- `js/net.js`: онлайн (пока не подключён)
- `models/`: сжатые glb-модели, авторы в `models/CREDITS.md`
- `js/main.js`: игровой цикл, камера, интерфейс, звук
