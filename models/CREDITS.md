# 3D-модели

Все модели распространяются по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Файлы сжаты для игры (meshopt + WebP, лёгкое упрощение сетки).
У Nexia убраны спойлер, козырёк над задним стеклом, шашка такси, лишние слои тонировки, флажки в салоне и дубли колпаков; стёкла получили отдельный материал (скрипт `fix-nexia.mjs`).
